# Kalshi Crypto Closing Gap Analyzer

Live dashboard for Kalshi 15-minute crypto markets in the final 4 minutes.

### How to Use:
1. Put your daily history files in `data/history/`
2. Run `CLOSING_GAP_LIVE_ONLY=1 python closing_gap.py`
3. Open `closing-gap-live.html`

Made for fast closing velocity analysis.
